# حالة الميزات

**ملاحظة صادقة:** لا شيء هنا تم بناؤه أو اختباره فعلياً بعد. بيئة العمل التي كُتب فيها الكود لا تملك Android SDK ولا إنترنت للبناء،
فأول تحقق حقيقي هو أول تشغيل لـ GitHub Actions، ثم التجربة على التلفاز.

## مكتوبة في الكود (المرحلة 1) — بانتظار أول بناء واختبار

- الساعة والتاريخ
- اكتشاف التطبيقات المثبتة وتشغيلها
- المفضلة (زر Menu أو ضغط مطوّل)
- آخر التطبيقات المستخدمة
- اختصارات الإعدادات والواي فاي والبلوتوث
- تنقل بالريموت وتمييز العنصر المحدد
- عربي/إنجليزي حسب لغة النظام
- تسجيل التطبيق كـ Home Launcher
- GitHub Actions: بناء APK، رفعه كـ Artifact، Release عند Tag
- التوقيع عبر GitHub Secrets فقط

## غير موجودة بعد

- الطقس، الخلفيات السينمائية، معلومات الجهاز
- المجلدات، إخفاء التطبيقات، ترتيب التطبيقات، البحث، خيارات التطبيق
- قسم MY FAVORITE TEAM بالكامل (يحتاج مزود API ومفتاحاً)
- Live Match Center، الإشعارات، Matchday Mode
- مركز الترفيه والتكامل مع Ayham Player
- Control Center المتقدم
- الثيمات، شاشة التوقف، تغيير حجم الأيقونات والخط
- Kids Mode، App Lock، PIN، Backup & Restore
- اختبارات آلية
